A comprehensive repository documenting my learning journey, coding labs, and projects through the **Clinical Data Science Specialization** offered by the **University of Colorado** on Coursera[cite: 1].

This specialization spans 6 main courses:
1. **Introduction to Clinical Data Science**
2. **Clinical Data Models and Data Quality Assessments**
3. **Identifying Patient Populations**
4. **Clinical Natural Language Processing**
5. **Predictive Modeling and Transforming Clinical Practice**
6. **Advanced Clinical Data Science**
